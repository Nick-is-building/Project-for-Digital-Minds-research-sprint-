# Archive

Files kept for the historical record. None of them are needed to reproduce the paper.

- `watchdog.sh` — the systemd-based process supervisor used to run and stop the main experiment. Documents how the run was supervised. Not reproduction material.
- `pilot_phase_data/` — raw output from the two pilot runs that preceded the main experiment. Superseded by the 900-observation main dataset in `pilot/out/`.
- `smoke_test_evidence/` — raw call log from the first smoke test. Supports the specific claim in Appendix D that 52 of 128 rating calls failed before the thinking-block fix. See the note in that directory.
